# ❤️ Queres Namorar Comigo?

Uma aplicação interativa desenvolvida em Python
utilizando a biblioteca Tkinter.

## Funcionalidades

- Interface gráfica romântica
- Botão SIM com mensagem personalizada
- Botão NÃO com movimento aleatório

## Tecnologias

- Python 3
- Tkinter
- Random

## Como executar

```bash
python main.py
